## Findings

- The Claude `setup-token` TUI and the Codex TUI switch the terminal to extended key reporting, so `tmux send-keys Enter` arrives as an escape they ignore; a raw carriage return (`send-keys -H 0d`) submits. Only matters when driving them from tmux, as `ms` does with `pane`-style sends.
- Codex run from `$HOME` warns that `~/.codex/config.toml` is "project-local" (it sits in the cwd's `.codex/`). A Codex quirk, cosmetic.
- The accounts table needed a PROVIDER column (two `tulp` rows were indistinguishable) — added in 0.2.2.
- A second sign-in as the wrong browser account (`dirk` signed in as `kratuvak`'s organisation, on the laptop) left the wrong grant in place and the retry skipped the login — fixed in 0.2.2 (a refused sign-in is discarded; `--relogin`; the doctor runs `verify`'s organisation check).
