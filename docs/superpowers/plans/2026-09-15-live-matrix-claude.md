## Bugs found (become fix tasks before Plan 2)
- **B1** A session with no transcript yet (no `activity` in any generation) must be relaunched with `--session-id <id>` (a new conversation with the same id), never `--resume <id>`.
- **B2** The readiness wait must watch `#{pane_dead}` each poll and fail fast with the screen tail when the launched CLI dies, instead of waiting the full 60 s.
- **B3** A launch that exits non-zero within seconds (pane_dead_status ≠ 0) is `died`, not a normal end, even though its SessionEnd hook recorded `ended`; `_pane_died`/reconcile must read `#{pane_dead_status}`.
- **B4** (minor) The continuation prompt, when the last user turn was trivial or already answered, makes the model invent work (it explored the repo and proposed deleting untracked dirs); tighten the wording: continue only an unfinished task, otherwise say so and wait.
- **B5** The Claude hook's SessionStart `resume` for the current generation should move `resuming → continuing` itself, so a session whose worker died after the respawn is adopted immediately rather than at reconcile's stuck-state threshold.
- **B6** `readLaunchToken` must treat an unreadable token file (EACCES) like a missing one — a `no-token` attempt with the reason — never a thrown error; and the transaction's catch-all must release (or fail) the recovery it owns instead of leaving it `owned` for reconcile to reclaim.
